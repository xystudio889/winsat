A recreation of the old Windows benchmarking tool, written with WinUI 3.

## Installation

1. Download the binaries package from [Release](https://github.com/xystudio889/winsat/releases)
2. After extracting, right-click the cer file and click Install.
3. Select "Local Machine" as the storage location, then click "Place all certificates in the following store".
4. Click "Next", then select "Trusted Root Certification Authorities" as the store.
5. Click "OK", then click "Next" to finish.

> You can view [video.mp4](./video.mp4) for a visual guide to the installation.

## Usage

1. Launch the app from the "Start Menu".
2. If you have not run a benchmark yet, you can follow the prompts to run one.
3. If you already have a benchmark score, the software will display a simple view; you can also check "Advanced Information" to view detailed information.
4. If you want to share your benchmark score, you can click "Export" in "Settings" to export it.

## Manual Build

1. Download [Visual Studio](https://visualstudio.microsoft.com/)
2. Check `WinUI application development`
3. Click `Build` at the top.
