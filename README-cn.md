使用winui3写的还原老版本Windows 跑分工具。

## 安装

1. 从 [Release](https://github.com/xystudio889/winsat/releases) 下载binaries安装包
2. 解压后右键点击cer文件，点击安装
3. 选择存储位置为“本地计算机”，点击“将所有的证书都放入下列存储”
4. 点击“下一步”，选择路径为“受信任的根证书颁发机构”
5. 点击“确定”，点击“下一步”完成。

> 你可以阅览 [video.mp4](./video.mp4) 来可视化安装。

## 使用

1. 从 “开始菜单” 启动应用
2. 如果你没有跑分，可以根据提示来跑分
3. 如果你已经有跑分，软件会显示简单视图；你也可以查看 “高级信息” 来查看详细信息。
4. 如果你要分享你的跑分，可以在 “设置” 中点击 “导出” 来导出你的跑分。

## 手动编译

1. 下载 [Visual Studio](https://visualstudio.microsoft.com/)
2. 勾选`Winui 应用程序开发`
3. 点击上方`生成`即可
